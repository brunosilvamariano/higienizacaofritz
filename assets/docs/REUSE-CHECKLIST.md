# Checklist de reutilização

## Identidade
- [ ] Nome/marca substituídos.
- [ ] Logo e favicon revisados.
- [ ] Paleta e tokens revisados sem quebrar contraste.
- [ ] Fontes e licenças confirmadas.

## Conteúdo
- [ ] Título e description únicos.
- [ ] Todos os textos revisados.
- [ ] WhatsApp/telefone corretos.
- [ ] Redes sociais corretas.
- [ ] Endereço/mapa corretos.
- [ ] `alt` das imagens descreve o conteúdo real.
- [ ] Nenhum dado do cliente anterior permanece.

## SEO/social
- [ ] Canonical com domínio real.
- [ ] `og:url`, `og:image` e `twitter:image` absolutos.
- [ ] Sitemap/robots configurados.
- [ ] Schema.org adicionado apenas com dados verdadeiros.

## Acessibilidade
- [ ] Um `h1`.
- [ ] Hierarquia de headings coerente.
- [ ] Navegação completa por teclado.
- [ ] Foco visível.
- [ ] Contraste revisado.
- [ ] Zoom a 200% sem perda de conteúdo.
- [ ] Reduced motion respeitado.

## Performance
- [ ] Hero otimizado e preload justificado.
- [ ] Imagens abaixo da dobra com lazy loading quando apropriado.
- [ ] Nenhuma imagem desnecessariamente grande.
- [ ] Build sem arquivos órfãos relevantes.

## Produção
- [ ] HTTPS.
- [ ] Headers de segurança.
- [ ] IDs reais de Analytics/Ads/Pixel, se utilizados.
- [ ] Consentimento/privacidade revisados quando aplicável.
- [ ] Links e CTAs testados em dispositivo real.
