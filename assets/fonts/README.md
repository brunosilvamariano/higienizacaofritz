# Fontes locais

Os arquivos WOFF2 não são versionados neste pacote.

Após executar `npm install`, o script `postinstall` copia automaticamente os pesos necessários dos pacotes `@fontsource/inter` e `@fontsource/lora` para esta pasta.

Arquivos esperados:
- inter-latin-400-normal.woff2
- inter-latin-700-normal.woff2
- inter-latin-800-normal.woff2
- lora-latin-700-italic.woff2

A Inter permanece como tipografia principal. A Lora Italic é usada somente em pequenos detalhes editoriais do Hero, FAQ e Contato.

Não há carregamento de Google Fonts, CDN ou fonte remota em tempo de execução.
