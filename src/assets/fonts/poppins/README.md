# Poppins

Fontes oficiais obtidas de https://github.com/google/fonts/tree/main/ofl/poppins em 15/10/2026. SIL OFL em OFL.txt. Pesos 400, 500, 600 e 700; itálico 400.

Em 17/10/2026 os TTF originais foram comprimidos para WOFF2 com fontTools 4.67.0 e Brotli 1.2.0, sem subset. Glifos e métricas foram comparados após a conversão. Os TTF permanecem no arquivo local recuperável work/cleanup-2026-10-17, fora do build.
