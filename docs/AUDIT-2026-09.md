# Auditoria técnica — setembro de 2026

## Escopo preservado

Esta revisão não altera o layout, a navegação, as animações, os links de contato ou a linguagem visível do site.

## Validado

- Documento em `pt-BR`, com um único `main`, um único `h1`, skip link e âncoras internas válidas.
- Imagens do HTML com atributo `alt`; imagens decorativas mantêm `alt` vazio.
- Navegação, botões, accordion FAQ e menu lateral usam rótulos ARIA e estados acessíveis.
- CSS e JavaScript continuam organizados por componente/seção; tipografia, imagens e ícones estão locais.
- Responsividade usa tokens, `clamp()`, `calc()` e suporte a `prefers-reduced-motion`.
- Canonical, robots, sitemap, Open Graph, Twitter Card, favicons e manifest estão configurados para `https://higienizacaofritz.com.br/`.
- Schema `LocalBusiness` válido com telefone, endereço, Instagram, serviços e área atendida: Joinville, Itapoá, São Francisco do Sul, Balneário Camboriú, Balneário Piçarras, Balneário Barra do Sul e Barra Velha.
- Build copia o HTML, assets, `robots.txt` e `sitemap.xml` para a pasta de publicação.
- Cabeçalhos não invasivos de segurança configurados para hospedagem Vercel.

## Preparação comercial futura

Google Ads, Google Analytics e Meta Pixel não foram inseridos com códigos fictícios. A inclusão deve ocorrer somente com IDs do cliente e consentimento configurado. Consulte `docs/TRACKING.md`.

## Comandos de validação

```bash
npm run audit
npm run build
npm run preview
```

## Pós-publicação recomendado

Após o domínio estar apontado, confirmar o domínio no Google Search Console, enviar o sitemap e testar a prévia do link no WhatsApp. Métricas de desempenho devem ser medidas na URL pública, pois dependem da hospedagem e da conexão real.
